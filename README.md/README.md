# House Price Analysis

## Objective

To study the relationship between property characteristics and house prices using exploratory data analysis, feature engineering, and data visualization.

## Dataset

The project uses a house price dataset containing property characteristics and house prices.

## Tasks

- Exploratory Data Analysis
- Feature Engineering
- Data Visualization
- Git Version Control
- GitHub Repository Management

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git
- GitHub
